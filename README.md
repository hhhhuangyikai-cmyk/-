# 桃花坪校区三维导览 离线版

这是桃花坪校区三维导览地图的离线交付版本。项目无需联网、无需数据库或后端服务，解压后即可在本机浏览校园三维模型、查找建筑和生活服务点，并提交本机保存的评价与问题反馈。

## 主要功能

- 三维校园浏览：旋转、缩放、平移和一键恢复视角。
- 建筑与场地展示：建筑体块、道路、边界、运动场地和入口标记。
- 地点筛选：全部地点、快递寄取、生活服务、打印复印、餐饮饮品。
- 智能搜索：支持服务地点、分类、位置、简介和建筑名称检索。
- 地点详情：查看图片、分类、相对位置、简介和公开评价。
- 评价与反馈：支持星级评价、文字评价及地点问题反馈；新内容先进入待审核状态。
- 本地管理员：可发布或删除评价，处理或删除反馈。
- 响应式界面：兼容桌面端和窄屏浏览。

## 运行方法

推荐双击 `启动离线导览.cmd`，再在浏览器中打开提示的本机地址（默认 `http://127.0.0.1:8765`）。

也可以直接打开 `桃花坪校区三维导览-离线版.html`。如浏览器限制本地文件加载，请使用推荐的启动脚本。

详细说明见 [离线使用说明.txt](离线使用说明.txt)。

## 文件说明

- `桃花坪校区三维导览-离线版.html`：主入口页面。
- `启动离线导览.cmd`：启动本地静态服务。
- `附属文件/`：三维模型、图片、脚本、第三方库和服务启动脚本。
- `离线使用说明.txt`：离线运行与常见问题说明。

## 本地数据说明

评价、待审核评价和反馈均保存在当前电脑浏览器的本地存储中，不会自动上传或跨设备同步。清除浏览器站点数据会清除这些本地记录。

管理员演示账号为 `admin`，密码为 `123456`。该账号仅用于课程展示和本地演示，不适合正式生产环境。

## 技术构成

项目采用 HTML5、CSS3、原生 JavaScript 与 Three.js/WebGL 开发；使用 OrbitControls 控制三维镜头、CSS2DRenderer 显示标签、OBJLoader 加载本地模型，并通过 localStorage/sessionStorage 保存离线数据和会话状态。
